## Computer Vision & ML Research
- **[WorldExam: Benchmarking World Models from Apparent Appearance to Inherent Reactivity](https://arxiv.org/abs/2608.02603)** (cs.CV, 2026-08-03): Hierarchical diagnostic benchmark for controllable video generation models across four levels (Visual Quality, Control Adherence, Spatial Consistency, World Reactivity). 1,474 cases, 8 tasks, evaluates 20 models. Reveals capability split: camera-driven excel at control but lack interaction; action-driven control subjects precisely but leave world unresponsive; language-driven better at interaction but weaker on complex controls.
- **[VR3D: View-Robust 3D Representation Learning for Aerial-Ground Person Re-Identification](https://arxiv.org/abs/2608.02598)** (cs.CV): Maps images into unified 3D coordinate space for view-independent features. 3D Geometry-Semantic Attention + Reliability-Aware Fusion. 5.63% Rank-1 improvement on CARGO dataset. Code forthcoming.
- **[CAPEval: A Decoupled Caption Evaluation across Understanding and Generation](https://arxiv.org/abs/2608.02589)** (cs.CV): Decomposes caption quality into Coverage (factual completeness) and Precision (factual correctness). 10 captioners tested across 4 model families. Coverage correlates with understanding; Precision correlates with generation. Dataset at https://liuzhipenggg.github.io/CAPEval/
- **[UEmbed: Unified Sparse and Dense Multimodal Embeddings](https://arxiv.org/abs/2608.02583)** (cs.CV, cs.AI, cs.CL, cs.IR): Decoder-only model producing both sparse lexical and dense representations in one causal forward pass. 2B/4B/9B scales. UEmbed-9B reaches 71.8 (dense) and 71.0 (sparse) on MMEB-v2. Code forthcoming.
- **[AtumAI: A Principled Framework for Agentic Generation of Datacenter Control-Plane Policies](https://arxiv.org/abs/2608.02569)** (cs.AI): Formal, transferable, systematic agentic policy generation. Datacenter Task Compiler (formal spec) + Evolutionary Design Discovery Loop (diffusion + EA + surrogate). Outperforms expert baselines on workload placement, resource scaling, power management.
- **[Structured Memory for Edge Language Models: PRECOG / SMC](https://arxiv.org/abs/2608.02560)** (cs.LG, cs.AI, cs.IR): O(1) SSM state injection for RAG — pre-encodes corpora as hidden states, injects at query time. 4500x prefill speedup (27s → <6ms) on 1.2B TENNs-LLM. Hierarchical persistent memory with cognitive-domain clustering. Architecturally impossible for Transformers.
- **[A Taxonomy of Cognitive Capability Gaps in Generative and Agentic AI](https://arxiv.org/abs/2608.02553)** (cs.AI): Five-dimension taxonomy (persistent state, goal-directed autonomy, self-monitoring, environment interaction, learning/adaptation) + Adaptive Cognitive Intelligence Architecture (ACIA) proposal. 15 pages, roadmap toward AGI.
- **[Magnet: Detecting Cross-Session AI Misuse Through Capability Accumulation](https://arxiv.org/abs/2608.02518)** (cs.AI): Cross-session goal decomposition as evasion technique. Magnet aggregates capabilities across sessions at user-level correlator, attracts "needles from haystack" into compact evidence bundle for detection.
- **[Token Radius Attention for Efficient Video Generation](https://arxiv.org/abs/2608.02504)** (cs.CV): Training-free framework mapping query entropy to analytic token budget with temporally decayed radius. Retains 9-19% attention interactions, 1.56x-2.05x speedup on Wan2.1/2.2, HunyuanVideo. Code: https://github.com/IF-LAB-PKU/Token-Radius-Attention
- **[CMuon: Accelerating Diffusion Transformer Training via Chunked Momentum Orthogonalization](https://arxiv.org/abs/2608.02502)** (cs.AI): Partitions fused DiT weights (AdaLN, QKV) into independent sub-components before Muon orthogonalization. 675M DiT achieves FID 1.18 on ImageNet 256 in 200 epochs — 2x speedup over AdamW, overcomes vanilla Muon plateaus. ECCV 2026.
- **[SWE-Touch: Benchmarking Coding Agents When Users Touch the Code](https://arxiv.org/abs/2608.02499)** (cs.SE, cs.AI): Stress-tests agents in shared workspaces with validated Counter-Edits (plausible conflicting edits). 7.7 pp resolve rate drop on SWE-bench Verified. Reveals limited workspace awareness — agents retain conflicting code without re-inspecting. Code: https://github.com/Trae1ounG/SWE-Touch
- **[DyFrDet: Towards Accurate Small Object Detection via Dynamic Frequency Suppression](https://arxiv.org/abs/2608.02495)** (cs.CV): Dynamic Frequency-aware FPN + Label Disambiguation Module. SOTA across multiple SOD benchmarks. Code: https://github.com/ManOfStory/DyFrDet
